# STEP to parametric code

Reconstruct `target.step` as a parametric modeling program using the assigned
CAD library. Match the complete part in millimetres, including its position
and orientation. `preview.png` is an overview; inspect the STEP when needed.

During investigation you may read and measure the target. Your submitted
program must build the geometry from explicit parameters and modeling
operations. It runs in a **clean directory without the target or investigation
files**. Leave the final model in `result`.

Do not copy, import, embed, or serialize the target geometry as your answer.
The intended output is an editable reconstruction. Geometric scoring alone
cannot prove editability; retained programs require source review.
